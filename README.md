# LoginID Homebrew tap

Install the LoginID AI Gateway CLI:

```sh
brew install loginid1/tap/aigw-cli
aigw --version
```

Upgrade with `brew upgrade aigw-cli`.

The casks in `Casks/` are written by the release workflow in
[loginid1/loginid-aigw-cli](https://github.com/loginid1/loginid-aigw-cli). Do not edit them by hand.
